📝 Simple To-Do List CLI
A clean, object-oriented Command Line Interface (CLI) application built with C# and .NET. This project demonstrates fundamental programming principles, including CRUD operations, user input validation, and structured software design.

🚀 Why I Built This
I created this project to practice building functional console applications while focusing on clean code and logic separation. It serves as a foundation for understanding how users interact with data through a terminal interface.

🛠️ Key Technical Features
CRUD Operations: Users can Create, Read, Update, and Delete tasks efficiently.

Input Validation: Robust handling of user entries to prevent crashes and ensure data integrity.
Object-Oriented Approach: Organized using classes and methods for better maintainability.

💻 How to Run It
To get a local copy up and running, follow these simple steps:

1. Clone the repo: git clone https://github.com/daviddimi/simple-todo-list-cli.git
2. Open the project Open the .sln file in Visual Studio or navigate to the folder in your terminal.
3. Run the app: dotnet run
