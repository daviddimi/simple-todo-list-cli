# Simple To-Do List CLI

A clean, object-oriented Command Line Interface (CLI) application built with **C#** and **.NET**, demonstrating fundamental programming principles including CRUD operations, input validation, and structured software design.

## Overview

Simple To-Do List CLI lets a user create, view, update, and delete tasks from a simple, menu-driven console interface. The project was built to practice functional console application design while focusing on clean code and separation of logic.

## Tech Stack

- **Language:** C# (.NET)
- **Architecture:** Object-oriented — Models / Services / Console UI



## Key Features



### Tasks

- Add a task
- View all tasks
- Update a task
- Delete a task



### Design

- **CRUD Operations** — full create, read, update, delete workflow for tasks
- **Input Validation** — robust handling of user entries to prevent crashes and ensure data integrity
- **Object-Oriented Approach** — organized using classes and methods for maintainability
- **State Management** — tasks are tracked in memory during a session using a `List`



## Getting Started



### Prerequisites

- .NET SDK
- Visual Studio 2022 (or any IDE with .NET support)



### Setup

1. Clone the repository
  ```
   git clone https://github.com/daviddimi/simple-todo-list-cli.git
  ```
2. Open the `.sln` file in Visual Studio, or navigate to the folder in your terminal.
3. Run the app:
  ```
   dotnet run
  ```



## Example Usage

```
1. Add Task
2. View Tasks
3. Update Task
4. Delete Task
5. Exit
```
